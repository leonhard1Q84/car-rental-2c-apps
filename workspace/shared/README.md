# 共享契约参考

本目录从原 `selfservice_rental` 仓库保留稳定的跨系统契约，供租车客户端理解订单、押金、车辆、门店和取还车数据。

- `schema/`：领域数据结构。
- `api-contract/`：外部车辆能力接口参考。
- `glossary/`：稳定术语。
- `event-taxonomy/`：事件分类。
- `templates/`：规格模板。

保留原字段和跨角色语义，避免因拆仓修改数据契约；涉及商户的描述属于外部系统上下文。原仓库的商户资产、历史参考工程与子模块不在本仓库维护。

接口文档的存在不代表当前应用已完成真实接口接入。后续跨仓同步须记录来源和版本，不得默认两边自动同步。
